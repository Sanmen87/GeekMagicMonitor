# GeekMagicMonitor

[English installation guide](README.en.md)

Часы, погода и мониторинг ПК на **GeekMagic HelloCubic Lite**. Приложение Windows
получает датчики CPU/GPU/RAM, запрашивает погоду и рисует цветные экраны на кубе
по локальному HTTP API. Прошивка обеспечивает Wi-Fi, рисование, OTA и автономные
NTP-часы после 15 секунд без кадров от компьютера.

Проверено на одном HelloCubic Lite: ESP8266, Flash 4 МиБ, ST7789 240×240.
Другие ревизии требуют проверки аппаратного профиля.

## Возможности

- Два крупных экрана: часы, дата, погода; температуры и нагрузка CPU/GPU, RAM.
- Автоматическая смена экранов или ручной выбор, IP в служебной строке.
- Температура воздуха, влажность, скорость ветра в м/с и направление.
- Поиск города, wttr.in/Open-Meteo, кэш и отметки устаревших данных.
- Работа в трее, автозапуск окна, выбор видеокарты и часового пояса.
- Независимый выбор русского/английского языка приложения и экранов куба.
- Отдельный сборщик температуры CPU с однократной настройкой прав администратора.
- Частичные обновления экрана, повторные попытки при обрыве связи.
- Recovery Wi-Fi при отсутствии нашей файловой системы, обновление программы
  и LittleFS отдельно через веб-интерфейс.

Погоду получает компьютер. Без него куб показывает автономные часы.
Штатные функции производителя заменяются; его Wi-Fi настройки автоматически
не переносятся. Происхождение доработанной прошивки: [уведомления](THIRD_PARTY_NOTICES.md).

## Структура

```text
monitor/       WinForms, ядро, сборщик CPU и автоматические проверки
firmware/      доработанная прошивка ESP8266 и веб-интерфейс
tools/         установка сборщика, иконка, экспорт исходников
docs/          установка прошивки, датчики, разработка
licenses/      лицензии сторонних компонентов
build_monitor.ps1
build_firmware.ps1
```

Заводские BIN, исходный архив upstream, установщики, отчёты и экспериментальные
файлы в Git не входят. Сборки создаются в `artifacts/`. Персональный
`firmware/data/config.json` исключён из Git.

## Установка приложения Windows

Нужны Windows 11 x64 и [.NET Desktop Runtime 10 x64](https://dotnet.microsoft.com/download/dotnet/10.0).
Для сборки из исходников установите **.NET SDK 10 x64** вместо отдельного Runtime.
Исходники можно получить через [Git](https://git-scm.com/download/win) или ZIP.
Первая сборка требует доступа к NuGet.

Из PowerShell в корне проекта:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build_monitor.ps1
```

Скрипт запускает проверки и создаёт:

```text
artifacts/monitor/GeekMagicMonitor.exe
artifacts/sensor-agent/GeekMagicMonitor.SensorAgent.exe
```

Переносите всю папку приложения вместе с DLL и RuntimeConfig. Один EXE отдельно
не работает. Перед обновлением выйдите из старой копии через **трей → Выход**.
Для параллельной сборки: `build_monitor.ps1 -OutputDirectory .\artifacts\monitor-new`.

## Установка на куб

Нужна наша прошивка, штатный интерфейс производителя несовместим с этим клиентом.
Подробная инструкция: **[сборка и установка прошивки](docs/FIRMWARE.md)**.

Порядок: собрать `firmware.bin` и `littlefs.bin`, загрузить программу, подключиться
к recovery Wi-Fi, проверить размер Flash, загрузить LittleFS и настроить домашнюю
сеть. Адрес показывается на автономном экране или находится в DHCP-списке роутера.

Сначала проверьте оборудование и возможность восстановления. Обычный USB-разъём
проверенных часов не создавал COM-порт; для дампа и восстановления требуется UART.

## Первый запуск и передача данных

1. Запустите приложение обычным пользователем. Изначально показано демо,
   отправка выключена.
2. Введите IP куба **без** `http://` и пути. Стартовый адрес — `192.168.4.1`;
   после подключения к домашнему роутеру обычно нужен другой.
3. Снимите **«Демо-данные»**, выберите GPU, интервал опроса и режим экрана.
4. Включите **«Показывать погоду»**, найдите город и выберите результат.
   Можно ввести координаты вручную. Исходный пример — Учкекен, смените его на свой.
   Часовой пояс — Windows ID, например `Russian Standard Time`.
5. Нажмите **«Применить и сохранить»**, затем включите
   **«Отправлять на куб (HoloClawd)»**.
6. Успешная доставка отмечается **«Куб: кадр принят»**.

Флажок отправки сохраняется сразу при включении и выключении. После перезапуска
приложения или входа в Windows отправка возобновляется, если была включена.
При первой установке и загрузке старых настроек без этого поля она выключена.
Флажок автозапуска
запускает окно в трее; применение настроек сохраняет путь к текущему EXE.
Крестик прячет окно, пункт **«Выход»** завершает процесс.

Настройки, кэш погоды и журнал: `%LOCALAPPDATA%\GeekMagicMonitor`.
Поля **«Язык приложения»** и **«Язык куба»** переключают русский/английский
сразу, без перезапуска. Выбор сохраняется отдельно от остальных настроек.
Изначально приложение русское, куб английский — как в предыдущих версиях.
Для русских надписей на кубе обновите **только Firmware** текущим `firmware.bin`
через `/legacyupdate`; повторная загрузка LittleFS для языка не требуется.
При старой прошивке клиент покажет подсказку об обновлении вместо отправки кириллицы.
Автономные часы и веб-интерфейс прошивки пока остаются английскими.

Зеркальный предпросмотр меняет только окно. Компенсацию оптики на кубе задаёт
`lcd_rotation=4`; повторно отражать отправляемые кадры не нужно.

## Температура CPU без UAC при каждом запуске

Некоторым датчикам нужен официальный драйвер [PawnIO](https://pawnio.eu/).
Приложение самостоятельно его не устанавливает. Если CPU показывает N/A,
установите PawnIO и проверьте показания кнопкой запуска от администратора.
Если температура появилась, можно один раз настроить фоновый сборщик:

```powershell
# Просмотр плана, без изменения системы:
.\tools\setup_sensor_agent.ps1

# Установка: PowerShell от администратора ТОГО ЖЕ пользователя:
.\tools\setup_sensor_agent.ps1 -Install
```

Сборщик размещается в Program Files и запускается при входе в Windows. Обычное
окно читает свежую температуру из его снимка, остальные датчики опрашивает само.
Детали и удаление задачи: **[сборщик CPU](docs/SENSOR_AGENT.md)**.

## Если что-то не работает

| Проблема | Что проверить |
|---|---|
| Нет изображения | Верный IP, включённую отправку и `http://IP/api/v1/device` |
| Только автономные часы | Кадры от ПК не поступают; проверьте статус приложения |
| CPU N/A, GPU работает | PawnIO, пробный запуск от администратора, сборщик CPU |
| WEATHER STALE / N/A | Город, доступность сервера, выбор другого провайдера и обновление погоды |
| После первого этапа нет веб-интерфейса | Recovery AP и `/legacyupdate`; см. инструкцию прошивки |
| Неправильная картинка | GPIO/SPI профиль и rotation для конкретной ревизии |

Отсутствующие датчики не подменяются нулём. Снимок CPU старше 10 секунд
отбрасывается. Погода старше 30 минут помечается устаревшей, через 6 часов
перестаёт использоваться. Доступность внешних серверов зависит от сети.

## Разработка и публикация

Команды тестов, предпросмотр, чистый экспорт и первый коммит:
**[руководство разработчика](docs/DEVELOPMENT.md)**.

Сборочные скрипты не прошивают устройство. API/OTA пока без авторизации:
используйте доверенную LAN, не открывайте порты куба в интернет.
Не коммитьте пароли. LittleFS с личным config также содержит их в извлекаемом виде.
