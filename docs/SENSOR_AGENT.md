# Фоновый сборщик температуры CPU

LibreHardwareMonitorLib получает GPU/RAM и загрузку CPU обычным процессом.
Для температуры некоторых CPU нужен официальный [PawnIO](https://pawnio.eu/)
и повышенные права. N/A означает недоступный датчик, а не нулевую температуру.

## Установка

1. Соберите приложение через `build_monitor.ps1`.
2. Установите официальный PawnIO с его сайта, проверьте действительную цифровую
   подпись установщика. Установщик не включён в этот репозиторий.
3. В приложении проверьте температуру запуском от администратора. Если датчик
   не появляется и так, установка сборщика сама по себе это не исправит.
4. Из корня проекта выполните просмотр плана:

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\setup_sensor_agent.ps1
   ```

5. Откройте PowerShell от администратора **того же пользователя**, перейдите
   в корень проекта и установите:

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\setup_sensor_agent.ps1 -Install
   ```

Папка установки: `%ProgramFiles%\GeekMagicMonitor\SensorAgent`.
Задача `GeekMagicMonitor-SensorAgent-<SID>` запускается при входе пользователя
с Highest/Interactive, без сохранения пароля, и сразу стартует при установке.
Задача не использует SYSTEM. Обычные пользователи имеют чтение/запуск файлов,
запись разрешена администраторам и SYSTEM.

Сборщик без окна опрашивает только CPU каждые 2 секунды. Он не принимает команд
и не обращается в сеть. Снимок температуры и времени атомарно заменяется в JSON
в защищённой папке. Приложение отбрасывает снимки старше 10 секунд и некорректные
значения. Кратковременная блокировка файла вызывает повтор записи; последняя
ошибка сохраняется в `last-write-error.log`. Права доступа к драйверу не меняются.

После установки запускайте основное приложение обычным пользователем. Автозапуск
его окна в трее настраивается отдельно в интерфейсе. Для обновления сборщика
повторите сборку и `-Install` от администратора.

## Отключение

```powershell
# PowerShell от администратора того же пользователя:
.\tools\setup_sensor_agent.ps1 -Remove
```

Скрипт останавливает сборщик и удаляет только свою задачу. Файлы установки
оставляет для ручной проверки/удаления. PawnIO этим скриптом не удаляется.

## Диагностика

```powershell
# Только локальные датчики, без погоды и рисования:
.\artifacts\monitor\GeekMagicMonitor.exe --diagnose-sensors .\sensors.json

# Два чтения сборщиком и выход, без установки задачи:
.\artifacts\sensor-agent\GeekMagicMonitor.SensorAgent.exe --probe .\cpu.json
```

Диагностические JSON содержат сведения об оборудовании. Храните их в `.local/`
или другой исключённой папке. Просмотр плана пишет XML в `.local/reports/sensor-agent`.
